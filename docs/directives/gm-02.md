# gm-02: Goal branches in the CLI: `start` on the goal branch, ordering, `land --goal`, `status`
Status: done
Goal: goal-model
Node: any
Deliverable: code
Land: goal
Verify: uv run --with pytest pytest -q && claude plugin validate . && ./bin/friday check --all
Hardware: none

## Goal
`friday start` puts a directive's work on its goal branch and refuses invalid or out-of-order
directives; `friday land` lands by the directive's Land field; `friday land --goal <g>` reverifies
every directive on the goal branch, pushes it and opens one PR whose body lists each directive's
Verify result and review verdict; `friday status` shows goals with progress. All of it is tested
against a local bare remote and a fake `gh`.

## Steps
1. `friday start <id>`: run the gm-01 checks for the directive and its goal (`check_repo`); refuse
   on errors, printing them. Refuse if any directive listed before it in the goal is not `done`,
   naming them. Refuse if tracked files have uncommitted changes and a branch switch is needed.
   Branch: Land `goal` or `none` -> `friday/<goal>`; Land `pr` -> `friday/<id>`. If already on it,
   stay; else switch to it if it exists locally; else create it from the goal's Base (local branch
   if it exists, else `origin/<Base>`; refuse if neither exists). Then set the directive's Status
   to `running@<host>` and, if the goal is `approved`, the goal's Status to `running`. Keep
   `--no-gate` and the active marker as they are.
2. `friday land <id>` (no `--base` needed; it defaults to the goal's Base): Land `pr` -> current
   behaviour (push `friday/<id>`, PR into Base). Land `goal` -> must be on `friday/<goal>` with a
   clean tree; push it (`git push -u origin friday/<goal>`), print `pushed friday/<goal>`, exit 0
   or 3; no PR. Land `none` -> print that nothing is pushed, exit 0. Keep exit codes 0/3/4/5.
3. `friday land --goal <g>`: must be on `friday/<g>` with a clean tree; every listed directive with
   Land `goal` must be `done` (refuse naming the rest). Rerun each such directive's Verify from the
   repo root (Deliverable `external`: not run, shown as `n/a (external)`); on any failure print
   which and exit 6 with nothing pushed. Read each directive's review verdict from the last Log
   line matching `Independent review: <verdict>` (`not recorded` if none), and any Log lines
   starting `Built:` or `Link:`. If the goal's Land is `none`: set the goal `done`, commit, exit 0
   without pushing. Else set the goal's Status to `done`, append a dated Log line, commit
   (message ends `Goal: <g>`), push, then the base and `gh` checks as in `land <id>` (4, 5 with
   the compare URL). PR title `<goal>: <goal title>`; body: the goal's `## Goal` text, then a
   table (directive, title, deliverable, Verify result, review verdict) and the Built/Link lines.
   If a PR for the branch exists, update its body (`gh pr edit --body-file`) and print it. Last
   line `PR: <url>` on success. A rerun after the goal is already `done` skips the status commit.
   Add exit 6 to the docstring.
4. `friday status`: goals first, each with status, base, `done/total`, then its directives in goal
   order (id, status, deliverable, title); directives in no goal under `(no goal)`; then the
   active marker and leases as now.
5. Tests in `tests/test_friday.py` (local bare repo as origin, fake `gh` on `$FRIDAY_GH` that
   records its argv and the body file): start creates `friday/<goal>` from Base, and the second
   directive reuses it; start of a Land `pr` directive makes `friday/<id>`; the ordering refusal;
   start refuses an invalid directive; `land <id>` for Land goal pushes the goal branch and opens
   no PR; `land --goal`: a failing Verify exits 6 and pushes nothing, base not on origin exits 4,
   missing gh exits 5 with a compare URL, fake gh receives a body naming every directive with its
   Verify result and verdict, goal Status ends `done`; `status` lists goals with progress.

## Out of scope
- The workflow calling these commands (gm-03).
- Parallel directives within one goal (follow-up: sub-branches merged into the goal branch).
- Dispatch to other nodes (fleet-02).
