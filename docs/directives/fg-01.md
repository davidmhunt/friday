# fg-01: friday knows each repo's forge (github, gitlab or none) and `friday check` warns when `Land: pr` cannot work
Status: proposed
Goal: gitlab-land
Node: any
Deliverable: code
Land: goal
Verify: uv run --with pytest --with pyyaml pytest -q tests/test_forge.py tests/test_docs.py tests/test_spec.py && uv run --with pytest --with pyyaml pytest -q && claude plugin validate .
Hardware: none

## Goal
One function decides the forge, so later directives branch on it instead of on URL regexes spread
over bin/friday. After this directive:
- lib/friday_core.py `forge(root) -> {"kind": "github"|"gitlab"|"none", "host", "slug", "web"}`:
  the `forge` key in .claude/friday.json wins (`github`, `gitlab`, `none`; another value is a
  `friday check` error); else origin's URL: `github.com` is github; a host whose name contains
  `gitlab`, or for which `glab auth status --hostname <host>` succeeds, is gitlab; anything else,
  or no origin, is none. `slug` is the project path (`group/sub/repo`, nested groups kept), `web`
  the https base URL. Handles ssh (`git@host:path.git`, `ssh://git@host:port/path.git`) and https.
- `friday check` warns once per goal with `Land: pr` (goal or directive) when the forge is `none`,
  or when it is `gitlab` and `glab` is not installed, naming the fix (`forge` key, install glab,
  or `Land: push`).
- `_gh_slug` and `_compare_url` in bin/friday use `forge()`; GitHub output is unchanged. For
  gitlab the compare URL is `<web>/<slug>/-/compare/<base>...<head>`.

## Steps
1. lib/friday_core.py `forge`, config key validation; bin/friday helpers use it.
2. `friday check` warning.
3. docs/spec.md (config table, a short forge section, `friday check`); tests/test_spec.py stays
   green. CHANGELOG `Unreleased` naming #20.
4. tests/test_forge.py: URL forms for github, gitlab.com, a self-hosted `gitlab.<host>` with
   nested groups, an ssh port, a host without "gitlab" recognised through a fake glab, an unknown
   host; the config override in each direction; the check warnings; compare URLs for both forges.

## Out of scope
- Bitbucket, Gitea or other forge APIs (they get `Land: push`).
