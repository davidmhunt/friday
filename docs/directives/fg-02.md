## Goal
The forge-neutral landing. After this directive `push` is a valid goal `Land:` value (GOAL_LANDS)
and `friday land --goal <g>` for such a goal does what it does for `pr` up to the push (reverify
every directive, push `friday/<goal>`, check Base is on origin) and then, instead of a PR, prints
`PUSHED: friday/<goal>` and, when the forge has a web URL, `COMPARE: <url>`, writes
`Landed: ... pushed friday/<goal> (no PR)` in the goal Log, and exits 0. The execute workflow's
Land phase treats it like `pr` (runs land after the last directive) and relays the COMPARE line.
`friday status` shows such a goal as `pushed` rather than `pr none`. Directive-level `Land:` values
are unchanged.
