## Goal
The skills and docs describe the goal model exactly as gm-01..03 implement it, so a planning
session writes a goal plus directives that pass `friday check` the first time, and a reader knows
how goal, directive and step relate and how each deliverable type is verified. The bench-01
migration is reported.
