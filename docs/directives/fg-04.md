## Goal
Everything else that asks the forge about PRs works on GitLab. After this directive, for a repo
whose `forge()` is `gitlab`:
- lib/friday_fleet.py merged detection (`gh pr list --state merged --head friday/<goal>`) uses
  `glab mr list --merged --source-branch friday/<goal> --output json`;
- `friday status` (bin/friday and lib/friday_status.py, which read PR state and URL per goal)
  shows `pr open|merged|closed <url>` from glab;
- the dash's open friday/* PR list (lib/friday_dash.py `refresh_prs`) lists GitLab MRs for repos
  whose reported forge is gitlab, via glab with the token from `glab auth token` passed like
  GH_TOKEN (environment, never argv); the dash image installs a pinned glab (multi-arch) next to gh;
- the merged-branch report (friday reports merged goal branches left on origin) works with glab.
When glab is missing or not signed in each of these degrades the way the gh path does today (no
PR info, no crash). `forge: none` repos show `pr none` and are skipped by the dash list.
