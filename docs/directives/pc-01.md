## Goal
The container's entry point. After this directive:
- `friday status --push --every N` (N seconds, minimum 5) pushes, sleeps N s and repeats until
  SIGTERM/SIGINT, which end it with exit 0 after the current push. A failed push prints its error
  and the loop goes on (it never exits on a dash outage). Without `--every`, `--push` is unchanged.
- `fs.collect` reads the host through environment overrides, each defaulting to today's path:
  `FRIDAY_PROC_ROOT` (health; default `/proc`), `FRIDAY_DISK_PATH` (disk usage; default `/`),
  `FRIDAY_TMUX_SOCKET` (passed as `tmux -S <path>` to every tmux call; default none) and the existing
  lease directory override if there is one (else add `FRIDAY_LEASE_DIR`). Sessions' cwds read from
  the pane are host paths: they are used as-is, since the container mounts the repos at the same
  absolute path.
- The snapshot says how it was collected: `push_mode: "timer" | "container"` (from `FRIDAY_PUSH_MODE`,
  default `timer`), shown in the dash's node card.

1. bin/friday `--every` on `status --push`; lib/friday_status.py overrides; dash node card shows the mode.
