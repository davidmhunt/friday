## Goal
A rule meant for the whole directive ("use Read/Grep/Edit/Write, not cat/grep/sed in Bash") today
lives in one step's text and never reaches the implementers of other steps. After this directive
the directive and goal formats accept an optional `## Rules` section (`- ` bullets), and
`.claude/friday.json` accepts `"rules": [...]` for the whole repo. `friday parse --json` returns
`rules`: the repo rules, then the goal's, then the directive's, in that order, deduplicated.
`workflows/execute.js` puts them, under a fixed heading ("Rules for this directive (from the
plan; they apply to every step)"), into every implementer, verify-fix, runner and reviewer prompt.
The reviewer treats a broken rule as a gap. `friday check` errors on a `## Rules` section without
a `- ` bullet and on a non-list `rules` in friday.json.

## Steps
1. lib/friday_core.py: parse `## Rules` on directives and goals; `load_config` reads `rules`
   (a list of strings, else a check error via the config validation used for
   `hardware_approval`); `friday parse --json` gains `rules`; `validate_directive` /
   `validate_goal` check the section.
2. workflows/execute.js: a `rulesBlock(d.rules)` appended to the implementer, Verify-fix,
   reviewer and second-review prompts (empty when there are none); the reviewer is told a broken
   rule is a gap. Keep the existing text otherwise.
3. skills/directive and skills/plan: describe `## Rules` (put directive-wide constraints there,
   never in one step's text; repo-wide ones in friday.json `rules`); docs/spec.md file formats,
   config table and parse JSON; tests/test_spec.py stays green. CHANGELOG `Unreleased` naming #27.
4. Tests: parse returns merged, ordered, deduplicated rules from all three sources; `friday
   check` errors on an empty `## Rules` and a non-list `rules`; a test (tests/test_workflow*.py
   or a string check on execute.js, following the existing workflow tests) shows the rules block
   is in every implementer and reviewer prompt.

## Out of scope
- Enforcing rules in the hook (tt-07 adds the one enforced rule).
