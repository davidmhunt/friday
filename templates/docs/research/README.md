# Research (Researcher namespace)

One memo per research/methodology question, named `<topic>_<date>.md`,
following `.friday/active/harness/templates/research_memo_template.md` (required section
headers, in order, and the standardized Sources bullet format). See
`.friday/active/harness/roles/researcher.md` for the full requirements and
`.friday/active/harness/tools/lint_research_memo.py` and
`.friday/active/harness/tools/check_unavailable_sources.py` for the mechanical checks the
Reviewer runs against every memo (format, and no citations of a bib key
listed under "Confirmed unavailable" in `docs/references/needs_pdf.md`).
Delete this directory (and the Researcher role) if your project has no
external-research component.
