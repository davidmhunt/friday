# Review (Reviewer namespace)

Reviewer-owned verdict documents: one file per closeout/audit pass, named
for what it verifies (e.g. `<directive-id>_closeout_verdict.md`,
`<topic>_audit_<date>.md`). These are the evidence trail behind a close-out on a `full`-level review (a `quick` review logs its evidence in
the directive's `## Log` and needs no file here). A verdict doc should show
its work (commands actually run, real output excerpts), not just assert a
result, per `.friday/active/harness/roles/reviewer.md`.

No verdict docs yet — this is an empty template directory.
