# Review (Reviewer namespace)

Reviewer-owned verdict documents: one file per closeout/audit pass, named
for what it verifies (e.g. `<directive-id>_closeout_verdict.md`,
`<topic>_audit_<date>.md`). These are the evidence trail behind a `[DONE]`
call in `.friday/active/harness/coding/tasks_finished.md` — a verdict doc should show its
work (commands actually run, real output excerpts), not just assert a
result, per the `[DONE]` definition in `.friday/active/harness/roles/reviewer.md`.

No verdict docs yet — this is an empty template directory.
